# MotoAsistente — App Web

Aplicación web para monitoreo de motocicleta con modelo 3D interactivo.

## Archivos

| Archivo | Función |
|---------|---------|
| `index.html` | App principal (5 vistas, modelo 3D, sensores) |
| `gamificar.html` | Editor de colores de la moto |
| `base_color.glb` | Modelo 3D de la motocicleta |
| `banners/` | Imágenes de banners publicitarios |

## Tecnologías

- HTML/CSS/JS (todo inline, sin build)
- Three.js 0.164.1 (CDN)
- localStorage para persistencia
